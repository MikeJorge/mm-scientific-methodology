**Public website (once deployed):** https://mikejorge.github.io/mm-scientific-methodology/

This repository is the **dedicated public distribution** for the controlled MM scientific software development and assurance methodology. It is separate from the [historical MHSMM software repository](https://github.com/MikeJorge/modulo-minimo-MHSMM) and from the private publication executor. The private executor, internal review receipts, credentials and unpublished operational evidence are **not** distributed here.

## Versioned public artifact

The proposed `gh-pages` branch serves exactly **17 HTML pages**, **five figure assets**, one CSS stylesheet, one sitemap, one public scientific reproducibility supplement ZIP, and a zero-byte `.nojekyll` file (26 Git file blobs). The **25 approved release files** are conserved byte for byte other than the 17 absolute sitemap URL mappings to this new repository.

The immutable prepared site snapshot is `releases/v1.0.2/MM_METHODOLOGY_V102_DEDICATED_GHPAGES_SITE_NOT_DEPLOYED_v1.0.0.zip`. See `PUBLIC_RELEASE_MANIFEST.json` for the full per-path SHA-256 and Git blob IDs and the target Git tree SHA-1. A public GitHub Pages deployment is **not evidence of validation or authorization of scientific execution**.

## Reproducibility and citations

- `REPRODUCIBILITY.md` explains the **scope and limits** of the public 12-source reproducibility supplement distributed within the site snapshot.
- `CITATION.md` contains human-readable citation guidance. No DOI has been assigned by this preparation step.
- `LICENSING.md` and the site's `/legal/copyright-licensing/` page define the **component-specific** licensing boundary. No new blanket MIT or CC BY license is issued.
- `/legal/privacy/` explains visitor privacy and contact information for the static site.
