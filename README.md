## Learning and application

The addition explains why conformity to a specification and suitability for intended use require distinct references. An original MM conceptual diagram draws on NASA's distinctions; it is not a NASA figure or certification.

The complete synthetic example follows a per-period need through two specifications, a data contract, code, tests and scoped decisions. The executable kit observed 44/44 function–fixture comparisons. A separate prospective task observes whether a new reader can identify needs and contracts, distinguish verification from validation, freeze acceptance criteria and recognize missing evidence.

**External participant evaluation has not been run; human participants observed = 0.** The prepared protocol does not establish empirical adoption effectiveness. The arithmetic example is not validation of a real agronomic model.
