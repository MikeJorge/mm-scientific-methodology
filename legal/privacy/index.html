This notice describes the static website as distributed and distinguishes its operation from data processing performed by the hosting platform. It is not an institutional privacy statement of the University of São Paulo or any cited partner.

1. What this website does

The released pages provide scientific documentation, figures and an optional downloadable reproducibility supplement. The website's delivered source does not contain account registration, sign-in, contact forms, visitor analytics scripts, advertising trackers, custom tracking pixels or code that intentionally sets first-party cookies or browser local storage. This statement describes the project files, not every technology that the hosting provider or the visitor's browser may use.

2. Hosting and access information

The website's public hosting is provided by GitHub Pages. GitHub states that it logs visitors' IP addresses for security purposes even if visitors are not signed in. GitHub may process technical usage information under its Privacy Statement. The website publisher does not claim control over GitHub's retention periods, infrastructure or cookie practices.

3. Purposes, third parties and retention

The project publishes public scientific content and does not maintain a separate visitor database through this static release. Web hosting, delivery, security logging and related technical processing may occur at GitHub. Consult the provider's privacy statement for its purposes, retention, rights-request mechanisms and any international processing. Following outbound links (including the GitHub repository, ORCID and official legal references) transfers the visitor to the linked service, whose policies then apply.

4. Cookies and preferences

The project does not implement nonessential tracking cookies in the distributed site. Accordingly, it does not display a project-managed tracking-consent banner. This is not a representation that GitHub or your browser never uses cookies. If analytics, embedded content or forms are added in a later release, this notice and any applicable consent controls must be reassessed before deployment.

5. Rights and how to contact the relevant party

Brazil's General Personal Data Protection Law (LGPD) provides rights that may apply to personal-data processing, including access, correction, deletion when legally appropriate and information about processing. For data collected by GitHub, consult GitHub's privacy-contact and rights channels. For privacy or LGPD-related requests concerning this website, contact the maintainer privately at rhallim.michael@gmail.com. For academic correspondence about the methodology, use rhallim.michael@usp.br. The academic email does not establish the University of São Paulo as the website operator or as controller of GitHub's processing.

Confidentiality: do not post identifying or sensitive personal information in publicly visible repository issues; use the private email contact above. When contacting the maintainer by email, the sender's address and message may be processed to respond to the request, including by the respective email providers. Avoid sending sensitive information unless necessary.

6. Updates to this notice

Any change adding analytics, forms, embedded third-party resources or a new responsible operator requires an updated notice. The currently distributed website has no automated newsletter or email subscription.
