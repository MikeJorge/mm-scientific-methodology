Glossary and acronyms¶

Version 1.0.3 documentary edition. This page is a source-bound editorial successor. Historical records and certified requirements are preserved; the published version 1.0.2 snapshot remains unchanged. This edition does not create scientific-runtime authority.

This page conserves Appendix A of the historical Technical Reference. Definitions remain non-normative explanatory text.

Term Definition
A0–A10 Registered multi-agent assurance roles.
A1 Sole mutable actor and sole external side-effect actor within an authorized gate.
A→readback→B Two-commit pattern: content commit, complete remote readback/reconstruction, certification receipt commit.
Architecture Certified constitutional authority defining invariants, gates, states, authority, and runtime barriers.
Authority Exact certified source that controls a decision: commit/tree, canonical artifact, package hash, or receipt.
CRS Coordinate reference system.
DCAT Data Catalog Vocabulary.
DQV Data Quality Vocabulary.
DOE Design of experiments.
Evidence Base Certified append-only project evidence system containing references, claims, decisions, conflicts, and gaps.
FAIL_CLOSED Policy under which missing, ambiguous, or inconsistent evidence leads to HOLD rather than inferred authorization.
GEE Google Earth Engine.
Gate Versioned stateful control boundary with authorities, actors, predicates, permitted effects, and terminal classes.
HOLD Terminal state denying progression until a localized defect is resolved prospectively.
IV&V Independent verification and validation.
Manual Certified subordinate normative companion implementing Architecture invariants as engineering controls.
MM Module Minimum project.
MHSMM Project economic/risk modeling system; exact expansion is controlled by project authorities.
Oracle Independent implementation used to compare expected semantics with the production resolver.
PROV-O W3C provenance ontology.
RC Release candidate.
RNG Random number generator.
SHACL Shapes Constraint Language.
SSDF Secure Software Development Framework.
UQ Uncertainty quantification.
