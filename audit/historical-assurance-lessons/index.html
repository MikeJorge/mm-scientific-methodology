Historical assurance lessons¶

Version 1.0.3 documentary edition. This page is a source-bound editorial successor. Historical records and certified requirements are preserved; the published version 1.0.2 snapshot remains unchanged. This edition does not create scientific-runtime authority.

The historical failure table is preserved as provenance/learning evidence. It does not mean each listed issue remains an active blocker.

Terminology: EPSG:6933 is a coordinate reference system identifier used in a historical control experiment; it is not a complete raster-grid specification. A RACI matrix distinguishes responsible, accountable, consulted, and informed roles. Neither term changes the recorded historical failure or its corrective action.

Historical failure Risk Prospective correction learned
Missing complete Phase A authority Protocol claims could not be independently verified Require complete source authority before adjudication
Unqualified EPSG:6933 positive control A control failure could not localize causality Prospective control qualification; no retroactive role change
Rule precedence ambiguity Multiple rules could be simultaneously true Explicit precedence and total/exclusive state partition
Manual v1.0.0 applicability/RACI gaps Requirements could not be mechanically resolved Typed context, applicability, responsibility, verification, and tailoring
Resolver executable not mutation-qualified Canonical source tests missed executable semantic drift Direct mutation tests against imported production resolver plus independent oracle
Stale RC2 references Byte-reproducible output still contained invalid paths Referential integrity validator and RC3 prospective correction
No file-capable GitHub transport Exact bytes could not be safely persisted Qualified automated executor in authenticated Codespaces
Browser upload denied Kit never reached Codespace Machine-mediated gh codespace cp transfer
Literal apostrophes in remote filename Exact-name discovery failed despite correct bytes Read-only forensic localization and atomic filename normalization
Outputs written under /tmp Stopping Codespace removed ephemeral outputs Exact-byte reconstruction and future persistence-destination preflight

Current-state separation¶

Historical Codespaces, /tmp loss, old local paths, and the architecture-era main snapshot remain evidence of why durability/readback controls exist. They are not the current local execution architecture. Figure 2 v1.0.6 is the current publication-facing local-adapter view, and it still grants no scientific runtime authority.
