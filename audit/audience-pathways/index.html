Audience pathways¶

The reading routes below are examples of evidence reconstruction for different disciplines. They do not establish different versions of the methodology or different certification standards. Where the historical examples use code-like notation, the cited registers provide exact identifiers.

Inherited v1.0.3 documentary content in the v1.0.4 learning edition. This page is a source-bound editorial successor. Historical records and certified requirements are preserved; the published version 1.0.2 snapshot remains unchanged. This edition does not create scientific-runtime authority.

The MM methodology uses one governed evidence base but exposes different reading paths.

Scientist¶

scientific question
→ intended use / estimand
→ modular scientific system
→ verification vs validation
→ uncertainty / sensitivity / robustness
→ model credibility
→ scientific claim discipline

Focus on Methodology §§1–2, 4, 7–8, 13–17, 22–24 and Figures 1–2.

Senior developer / solution architect¶

authority
→ four-plane execution-control core
→ modules and versioned contracts
→ Gate-governed SDLC
→ requirements / applicability / responsibility
→ tests / mutation assurance
→ release / exact-byte readback

Focus on Methodology §§3–12, 18–21 and the AR/DM/playbook/checklist views.

A guided route for developers

Use the V&V explanation, the worked example and the fresh-reader protocol to connect the method to a bounded task. The protocol observes five competencies and distinguishes first responses from assisted revisions. It has not yet been evaluated with external participants.
