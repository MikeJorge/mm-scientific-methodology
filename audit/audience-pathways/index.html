Audience pathways¶

The MM methodology uses one governed evidence base but exposes different reading paths.

Scientist¶

scientific question
→ intended use / estimand
→ modular scientific system
→ verification vs validation
→ uncertainty / sensitivity / robustness
→ model credibility
→ scientific claim discipline

Focus on Methodology §§1–2, 4, 7–8, 13–17, 22–24 and Figures 1–2.

Senior developer / solution architect¶

authority
→ four-plane execution-control core
→ modules and versioned contracts
→ Gate-governed SDLC
→ requirements / applicability / responsibility
→ tests / mutation assurance
→ release / exact-byte readback

Focus on Methodology §§3–12, 18–21 and the AR/DM/playbook/checklist views.

Auditor¶

claim
→ Architecture requirement
→ Manual requirement
→ applicability / responsibility
→ verification / evidence
→ source / authority
→ terminal state

Use the conservation crosswalk, AR↔DM view, 197-DM register, certified identities, Evidence Overlay, and historical QA receipt.

Nature Computational Science reviewer / editor¶

methodological contribution
→ generalizability
→ scientific validity beyond software correctness
→ reproducibility
→ independent assurance
→ limitations / non-claims
→ source completeness

Use Methodology §§1–2, 4–8, 17, 19, 22–26, Figures 1–2 and Source & reference register.
